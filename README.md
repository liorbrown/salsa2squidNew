# SALSA2 Integration into Squid-Cache

## Project Overview
This project advances the practical implementation of **SALSA2**, a distributed caching algorithm published by Dr. Itamar Cohen in the IEEE Transactions on Network and Service Management (TNSM), into a production-grade, widely deployed web caching proxy: **Squid-Cache**. The work is conducted as part of research activities at Ariel University by a research assistant under the supervision of Dr. Cohen.
